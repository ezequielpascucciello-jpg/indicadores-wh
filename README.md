# Diaria WH

Proyecto estático preparado para GitHub Pages.

## Publicación
1. Crear un repositorio nuevo en GitHub.
2. Subir `index.html`.
3. Ir a Settings > Pages.
4. En Build and deployment seleccionar Deploy from a branch, `main` y `/root`.

## Uso
- La aplicación incluye enero a mayo de 2026.
- `Cargar Excel` permite agregar un mes nuevo o reemplazar un mes ya cargado durante la sesión.
- Para publicar datos permanentes para todos los usuarios, actualizar los archivos fuente y regenerar/publicar `index.html`, o conectar posteriormente Power Automate a una fuente JSON del repositorio.
